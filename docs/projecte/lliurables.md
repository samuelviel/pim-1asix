# Lliurables i format

Totes les entregues del mòdul seguixen les mateixes normes. Llig esta pàgina una vegada al
principi de curs i torna-hi cada vegada que vages a lliurar.

---

## Nom del fitxer

```text
PIM_UP<n>_<Cognoms>_<Nom>.pdf
```

!!! example "Exemples"
    - `PIM_UP1_Viel_Malonda_Samuel.pdf`
    - `PIM_UP4_Garcia_Ferrer_Aitana.pdf`

Si el lliurable té diversos fitxers (per exemple, el document i un projecte de Packet
Tracer), comprimix-los en un ZIP amb el mateix nom:
`PIM_UP5_Cognoms_Nom.zip`.

---

## Format del document

| Element | Requisit |
|---|---|
| **Format d'entrega** | PDF sempre. La font (docx, odt, md) no es lliura |
| **Portada** | Títol del lliurable, nom de l'organització, el teu nom, curs i data |
| **Índex** | Obligatori a partir de la UP3 |
| **Capçalera o peu** | El teu nom i el número de pàgina a totes les pàgines |
| **Tipografia** | Cos 11 o 12, interlineat 1,15 o 1,5 |
| **Figures i taules** | Numerades i amb peu: *Figura 3. Esquema lògic de la xarxa* |
| **Extensió** | La que indique cada unitat, sense comptar portada, índex ni annexos |

---

## Apartats obligatoris a tots els lliurables

Independentment del que demane la unitat, **tot lliurable acaba amb estos tres apartats**:

### 1 · Quadern de seguiment

L'estat actual del teu [quadern](quadern.md), com a annex.

### 2 · Fonts

Totes les fonts consultades, amb URL i data de consulta. Format lliure però consistent.

```text
[1] IVACE. Ajudes per a la digitalització de pimes. https://www.ivace.es
    Consultat el 14 de novembre de 2026.
[2] Synology. DS224+ Datasheet. https://www.synology.com/...
    Consultat el 20 de gener de 2027.
```

### 3 · Declaració d'ús d'IA

Una taula breu i honesta. No penalitza usar-la; penalitza no declarar-la o no verificar-la.

| Eina | Per a què l'he usada | Com ho he verificat |
|---|---|---|
| ChatGPT | Generar un primer esborrany de la llista de riscos | He descartat 4 riscos que no aplicaven i n'he afegit 2 del meu cas |
| Claude | Revisar la redacció de l'apartat de viabilitat | He contrastat les xifres amb el pressupost de la UP4 |

Si no has usat cap eina d'IA, escriu-ho igualment: *No he utilitzat eines d'IA en este lliurable.*

---

## On es lliura

Sempre a **Aules**, a la tasca corresponent de la unitat. Res que s'entregue per correu,
per xat o en paper es considera lliurat.

!!! warning "Comprova l'entrega"
    Després de pujar el fitxer, torna a obrir la tasca i **descarrega'l**. Un PDF corrupte o
    un fitxer de 0 bytes compten com a no presentat.

---

## Terminis

| | |
|---|---|
| **Data límit** | La que indique la tasca d'Aules. Les d'esta web són orientatives |
| **Retard** | −1 punt per cada dia natural de retard |
| **Retard justificat** | Avisa **abans** del termini i aporta justificant |
| **Reentrega** | Si el lliurable queda per baix de 4,0, se't donarà una nova data i possiblement un repte nou |

---

## Checklist abans de lliurar

Copia-la i marca-la cada vegada:

- [ ] El document respon a **tots** els apartats de l'enunciat
- [ ] He rellegit la **rúbrica** i he comprovat cada criteri
- [ ] Parla de **la meua organització**, no de generalitats que servirien per a qualsevol
- [ ] Les decisions estan **justificades**, no només enunciades
- [ ] Les figures i taules estan numerades i referenciades al text
- [ ] Hi ha **quadern de seguiment**, **fonts** i **declaració d'IA**
- [ ] El nom del fitxer seguix el format `PIM_UP<n>_Cognoms_Nom.pdf`
- [ ] És un **PDF** i s'obri correctament
- [ ] L'he pujat a **Aules** i l'he descarregat per a comprovar-ho
