# Projecte Intermodular · 1r ASIX

Benvingut i benvinguda al mòdul de **Projecte Intermodular** del primer curs del CFGS
d'**Administració de Sistemes Informàtics en Xarxa**.

Este lloc web recull tot el que necessites durant el curs: els continguts de cada unitat,
les activitats avaluables amb les seues rúbriques, les plantilles i el calendari.
És públic: el pots consultar des de qualsevol dispositiu i sense contrasenya.

!!! tip "Com funciona el mòdul en una frase"
    Tries una organització real, li detectes les necessitats informàtiques i, unitat rere
    unitat, construïxes el projecte que les resoldria: anàlisi, disseny, planificació,
    execució i defensa.
