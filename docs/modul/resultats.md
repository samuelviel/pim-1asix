# Resultats d'aprenentatge i criteris d'avaluació

Un **resultat d'aprenentatge (RA)** diu *què has de saber fer* en acabar el mòdul.
Cada RA es desglossa en **criteris d'avaluació (CE)**, que són *com comprovem que ho saps fer*.
Tot el que farem este curs està penjat d'estos quatre RA i dels seus criteris.

!!! success "Este curs només s'avaluen els quatre RA propis del Projecte Intermodular"
    El mòdul **no incorpora resultats d'aprenentatge d'altres mòduls** del cicle. Els
    coneixements d'implantació de sistemes operatius, xarxes, maquinari o bases de dades
    els faràs servir com a **eina** per a resoldre el projecte, però **s'avaluen al seu
    mòdul**, no ací. El que ací s'avalua és la teua capacitat d'analitzar, dissenyar,
    planificar i controlar un projecte.

---

## Els quatre resultats d'aprenentatge

<span class="ra ra1">RA1</span> **Identifica necessitats del sector productiu, relacionant-les amb projectes tipus que les puguen satisfer.**

<span class="ra ra2">RA2</span> **Dissenya projectes relacionats amb les competències expressades en el títol, incloent-hi i desenvolupant-ne les fases que el componen.**

<span class="ra ra3">RA3</span> **Planifica la posada en funcionament o execució del projecte, determinant el pla d'intervenció i la documentació associada.**

<span class="ra ra4">RA4</span> **Definix els procediments per al seguiment i control en l'execució del projecte, justificant la selecció de variables i instruments emprats.**

!!! danger "Condició per a aprovar"
    Cal tindre **els quatre RA superats**. Un RA no es compensa amb un altre: si te'n queda
    un per assolir, el mòdul queda pendent encara que la mitjana isca alta.

## Criteris d'avaluació

### <span class="ra ra1">RA1</span> · Identificar necessitats del sector

| CE | Descripció | On es treballa |
|:--:|---|---|
| a | S'han classificat les empreses del sector segons les seues característiques organitzatives i el tipus de producte o servei que oferixen. | [UP1](../up1/index.md) |
| b | S'han caracteritzat les empreses tipus indicant l'estructura organitzativa i les funcions de cada departament. | [UP1](../up1/index.md) |
| c | S'han identificat les necessitats més demandades a les empreses. | [UP1](../up1/index.md) · [UP2](../up2/index.md) |
| d | S'han valorat les oportunitats de negoci previsibles en el sector. | [UP1](../up1/index.md) |
| e | S'ha identificat el tipus de projecte requerit per a donar resposta a les demandes previstes. | [UP2](../up2/index.md) |
| f | S'han determinat les característiques específiques requerides al projecte. | [UP2](../up2/index.md) |
| g | S'han determinat les obligacions fiscals, laborals i de prevenció de riscos i les seues condicions d'aplicació. | [UP2](../up2/index.md) |
| h | S'han identificat possibles ajudes o subvencions per a la incorporació de noves tecnologies de producció o de servei que es proposen. | [UP2](../up2/index.md) |
| i | S'ha elaborat el guió de treball que se seguirà per a l'elaboració del projecte. | [UP2](../up2/index.md) |

### <span class="ra ra2">RA2</span> · Dissenyar el projecte

| CE | Descripció | On es treballa |
|:--:|---|---|
| a | S'ha recopilat informació relativa als aspectes que seran tractats en el projecte. | [UP3](../up3/index.md) |
| b | S'ha realitzat l'estudi de viabilitat tècnica del projecte. | [UP3](../up3/index.md) |
| c | S'han identificat les fases o parts que componen el projecte i el seu contingut. | [UP3](../up3/index.md) |
| d | S'han establit els objectius que es pretenen aconseguir identificant-ne l'abast. | [UP3](../up3/index.md) |
| e | S'han previst els recursos materials i personals necessaris per a dur a terme el projecte. | [UP4](../up4/index.md) |
| f | S'ha realitzat el pressupost econòmic corresponent. | [UP4](../up4/index.md) |
| g | S'han identificat les necessitats de finançament per a la posada en marxa del projecte. | [UP4](../up4/index.md) |
| h | S'ha definit i elaborat la documentació necessària per al seu disseny. | [UP4](../up4/index.md) |
| i | S'han identificat els aspectes que s'han de controlar per a garantir la qualitat del projecte. | [UP4](../up4/index.md) |

### <span class="ra ra3">RA3</span> · Planificar l'execució

| CE | Descripció | On es treballa |
|:--:|---|---|
| a | S'han seqüenciat les activitats, ordenant-les en funció de les necessitats d'implementació. | [UP5](../up5/index.md) |
| b | S'han determinat els recursos i la logística necessària per a cada activitat. | [UP5](../up5/index.md) |
| c | S'han identificat les necessitats de permisos i autoritzacions per a dur a terme les activitats. | [UP5](../up5/index.md) |
| d | S'han determinat els procediments d'actuació o execució de les activitats. | [UP5](../up5/index.md) · [UP6](../up6/index.md) |
| e | S'han identificat els riscos inherents a l'execució, definint el pla de prevenció de riscos i els mitjans i equips necessaris. | [UP5](../up5/index.md) |
| f | S'ha planificat l'assignació de recursos materials i humans i els temps d'execució. | [UP5](../up5/index.md) |
| g | S'ha fet la valoració econòmica que dona resposta a les condicions de l'execució. | [UP5](../up5/index.md) |
| h | S'ha definit i elaborat la documentació necessària per a l'execució. | [UP6](../up6/index.md) |

### <span class="ra ra4">RA4</span> · Definir el seguiment i el control

| CE | Descripció | On es treballa |
|:--:|---|---|
| a | S'ha definit el procediment d'avaluació de les activitats o intervencions. | [UP6](../up6/index.md) · [quadern](../projecte/quadern.md) |
| b | S'han definit els indicadors de qualitat per a realitzar l'avaluació. | [UP6](../up6/index.md) |

| e | S'ha definit i elaborat la documentació necessària per a l'avaluació de les activitats i del projecte. | [UP6](../up6/index.md) |
| f | S'ha establit el procediment per a la participació en l'avaluació dels usuaris o clients i s'han elaborat els documents específics. | [UP6](../up6/index.md) · [UP7](../up7/index.md) |
| g | S'ha establit un sistema per a garantir el compliment del plec de condicions del projecte quan este existisca. | [UP6](../up6/index.md) |

!!! tip "Per què el RA4 apareix a totes les unitats"
    El RA4 va de **seguiment i control**, i això no es fa al final: es fa mentre el projecte
    avança. Per això a cada unitat n'avaluem un tros a través del
    [quadern de seguiment](../projecte/quadern.md), que mantindràs viu tot el curs.
